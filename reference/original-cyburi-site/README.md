# Reference only — not part of this project's build

These files are an archived copy of the original site this project was
inspired by (https://vbc.cyburi.com/VirtualCoach/RotationMaster.html),
kept here for future reference (e.g. comparing behavior, checking edge
cases in their per-system position tables). They are **not** imported,
linked, or built by anything in this repository.

- `RotationMaster.html` — the page markup/inline bootstrap script
- `vbCourts.js` — court/player SVG rendering (Apache 2.0 licensed)
- `vbTutorials.js` — rotation state, position tables, overlap checks, tutorial (Apache 2.0 licensed)
