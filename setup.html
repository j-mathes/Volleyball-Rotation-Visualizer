How to use it

Drag any player anywhere on the court. Rotating snaps every player to their zone's base position; dragging lets you test faults. The Libero can only swap in for a back-row player, and is automatically swapped out if that player would rotate to the front row. If the bench turns red, you've dragged its occupant onto a court that already has 6 players.

Libero Swap

Click "Swap In Libero", then click a highlighted back-row player to swap the Libero in for them.

Overlap Status

"Show Overlap Guides" and "Show Player Links" are independent toggles - while either is on, click a player to see its overlap boundaries and/or links to corresponding players. Double-click a player to lock the selection (pulses while locked) so you can move others without losing it; double-click again to unlock. "Lock to Legal Positions" is a separate toggle that clamps dragging so a player can't be moved past the fault line against its current row/column neighbors - turn it off to freely create (and see) overlap violations again.

Player Names

Customize what each player's on-court label shows (e.g. a jersey number instead of the position code). Limited to 3 characters so it still fits inside the player circle. Saved labels apply next time the visualizer page loads.

Colors

Customize the court, player, and UI colors used across the visualizer. Saved colors apply next time the visualizer page loads.

Line Thickness

Customize the stroke width (in pixels) of the player outline and the guide/violation/link lines. Saved thicknesses apply next time the visualizer page loads.

Font

Customize the font family and text sizes used for player labels, the BENCH label, and the "R#" rotation tracker. Saved fonts apply next time the visualizer page loads.

Glow & Pulse Effects

Customize the glow blur radius for selectable/selected player highlights, and the pulse animation shown while a selection is locked. Saved effects apply next time the visualizer page loads.

Saved Court Setups

Save the current on-court arrangement from the "Court Setups" section of the visualizer, then load, export, or delete it here. Loading opens the visualizer with that setup applied. Type a folder name next to a setup to group it with others; edit a folder's name directly in its header to rename it. Export/import work on a single setup or a whole folder.

    Court Setup Playlist

    Build an ordered sequence of saved setups to animate through automatically. Play it back (with play/pause/step controls) from the "Playlist Playback" section of the visualizer.

      3D Preview — Bench Side

      Only affects the 3D Preview page - the 2D visualizer already places the bench automatically for each net orientation. Choose which side of the 3D court the bench/Libero substitution area sits on.

      3D Preview — Label Scaling

      Only affects the 3D Preview page. "Scale with Distance" shrinks/grows each player's label as the camera gets farther/closer, matching the pucks' own perspective scaling; "Fixed Size" keeps every label the same screen size regardless of distance.
